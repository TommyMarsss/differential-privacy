# differential-privacy

基于 Laplace 机制的差分隐私计数查询系统（仅 Go 标准库，无第三方依赖）。

给定数据集与一系列计数查询，系统为每个查询结果注入 Laplace 噪声、对隐私预算
（ε）进行记账，超预算的查询会被拒绝并明确报告；处理完毕后生成一个单一静态
HTML 报告（数据与逻辑全部内嵌，无外部依赖）。

## 快速开始

```sh
go test ./...        # 运行全部测试（含噪声统计性质验证）
go run ./cmd/dpquery # 运行演示，生成 report.html
# 可选参数：-o 输出路径（默认 report.html）、-budget 预算上限（默认 4.0）、-n 记录数（默认 1000）
```

用浏览器打开生成的 `report.html` 即可查看：每次查询的真实值、加噪结果、
剩余预算（被拒绝的超预算查询整行高亮）、预算使用进度条与组合分析告警。

## 差分隐私模型

- **邻接数据集**：相差一条记录（add/remove 模型）。
- **查询类型**：计数查询 `count(P)`，其 L1 敏感度 Δf = 1（增删一条记录最多
  改变计数 1）。引擎也支持显式指定其他敏感度（`Query.Sensitivity`）。
- **Laplace 机制**：发布 `count(P) + Lap(b)`，噪声尺度 **b = Δf / ε**，理论
  方差 **2b²**。该机制满足 ε-差分隐私（纯 DP，δ = 0）。
- **噪声采样**：逆变换采样 `X = -b·sign(U)·ln(1-2|U|)`，`U ~ Uniform(-1/2, 1/2)`。
  生产路径使用 `crypto/rand`（`dp.CryptoSource`）——噪声若可预测，隐私保证
  即失效；测试与演示使用固定种子的 `math/rand/v2` 以便复现。
- **参数校验**：ε 与 Δf 必须为正有限值，非法参数的查询被拒绝且不消耗预算，
  防止尺度错误导致保护不足。

## 隐私预算记账规则

`dp.Accountant` 跟踪一个数据集上的累计消耗：

1. 每次**成功执行**的查询消耗其声明的 ε；
2. **被拒绝**的查询（预算不足或参数非法）**不消耗**预算；
3. 当 `已消耗 + 本次 ε > 预算上限` 时拒绝查询并返回
   `dp.ErrBudgetExhausted`（错误信息中包含本次所需、剩余与已用量）；
4. 恰好用尽预算（`已消耗 + ε == 上限`）的查询**允许**执行。

## 组合定理的适用范围

系统采用**基础序列组合**（basic sequential composition）：对同一数据集依次
执行 ε₁, ε₂, …, εₖ-差分隐私的查询，整体满足 **(Σ εᵢ)-差分隐私**。这就是
记账器直接累加 ε 的理论依据。

**不覆盖**高级组合（advanced composition）、RDP/zCDP 等更紧的界，也不做
并行组合优化（对不相交数据子集的查询仍按序列组合全额累加，是保守但安全的上界）。

### 低效查询模式识别

`dp.AnalyzeComposition` 在查询计划层面（依据 `Query.Key` / `Query.RefinesKey`
元数据）识别会导致预算快速耗尽的模式：

| 模式 | 说明 |
|---|---|
| 重复查询 | 同一语义键被多次查询，重复消耗预算，应复用首次结果 |
| 总数+子集冗余 | 已按某维度查询全部子集，子集之和即总数，总数查询的预算属于浪费 |
| 子集细化查询 | 对已查集合的子集再查询，ε 按序列组合全额叠加，提示考虑后处理替代 |

## 代码结构

```
dp/noise.go       Laplace 尺度计算与噪声采样（crypto/rand 随机源）
dp/accountant.go  隐私预算记账器
dp/engine.go      查询引擎：计数、预算校验、加噪、执行
dp/analysis.go    序列组合与低效查询模式识别
dp/report.go      单一静态 HTML 报告渲染（html/template，无外部资源）
cmd/dpquery/      演示程序：合成数据集 + 查询计划 → report.html
```

## 测试覆盖

- `dp/noise_test.go`：50 万样本验证噪声均值趋近 0（6σ 容差）、方差符合 2b²
  （2% 容差）、分布对称性；多组 (Δf, ε) 下尺度 b = Δf/ε 的正确性与非法参数拒绝。
- `dp/accountant_test.go`：多次查询预算累加、超预算拒绝且不消耗、恰好用尽、
  非法预算/消耗拒绝。
- `dp/engine_test.go`：真实计数正确性、加噪结果 = 真实值 + 噪声、超预算查询
  被引擎拒绝且给出原因、序列组合总损失 = Σ εᵢ、自定义敏感度、组合分析规则。
- `dp/report_test.go`：报告包含真实值/加噪结果/剩余预算/拒绝高亮，且不含任何
  外部资源引用。
